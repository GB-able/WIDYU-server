# 업로드 플로우

### UPLD1 \~ UPLD4

| 정책 항목 | 기능 ID | 순위   | 기능명    | 상세 설명                                                                                                                                                                                          | 배치 조건 |
| ----- | ----- | ---- | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- |
| 업로드   | UPLD1 | 구현 중 | 콘텐츠 선택 | 정렬 탭: 전체/동영상/사진<br>사진/동영상 즉시촬영 및 자동 선정<br>콘텐츠 나열: 기본 3열, 1회 축소 5열, 2회 축소 15열(2회 축소 배열은 선택 불가, 특정 선택 시 5열로 해당 위치 이동—iOS 갤러리 유사)<br>선택 제한: 사진 ≤10, 동영상 ≤3<br>선택 완료→ **UPLD2**(사진)/**UPLD3**(동영상) | 상시    |
| 업로드   | UPLD2 | 구현 중 | 사진 편집  | 선택 콘텐츠 1개씩 미리보기/개별 편집<br>슬라이드로 선택/편집 대상 전환<br>편집 완료→ **UPLD4**                                                                                                                                 | 상시    |
| 업로드   | UPLD3 | 구현 중 | 동영상 편집 | 선택 콘텐츠 1개씩 미리보기<br>**컷편집**, 재생시간 **3분 이내 제한**, **용량 500MB 이하로 다운그레이드**<br>개별 편집/슬라이드 전환<br>편집 완료→ **UPLD4**                                                                                    | 상시    |
| 업로드   | UPLD4 | 구현 중 | 게시글 작성 | 본문 최대 **2,200자**(공백 포함), 카운터 `x/2200자` 표기<br>업로드 시 “업로드 완료” 모달<br>텍스트: “부모님께서 미션을 완수하시면 게시물을 확인할 수 있어요.”                                                                                       | 상시    |

# 게시물/상세

### FEED1 (사진), FEED2 (동영상), FEED(예정)

| 정책 항목 | 기능 ID | 순위    | 기능명       | 상세 설명                                                                                                                                                                                                                                                                                                                              | 배치 조건 |
| ----- | ----- | ----- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- |
| 게시물   | FEED1 | 구현 중  | 사진 게시물    | 작성자(프로필/이름), 대표콘텐츠 1개(최초 선택 이미지)<br>콘텐츠 수: 1개면 아이콘 없음/여러 개면 아이콘 표기<br>열람자 표기: 1명 `{A}님이 읽었어요` / 2명 이상 `{A, B} 외에 여러 명…` (프로필 사진 최대 3명)<br>작성일시: 연·월·일·요일 (추후: 당일이면 “1시간 전” 등)<br>게시글: 2줄 초과 시 “더보기” → 클릭 시 **DETL** 이동<br>좋아요: 총 개수 표기, 토글 시 즉시 증감/색상 변화, **최초 좋아요 시 열람여부 반영**(이후 변경과 무관)<br>댓글: 총 개수(답글 포함), 아이콘 클릭 시 **DETL** 이동 | 상시    |
| 게시물   | FEED2 | 구현 중  | 동영상 게시물   | 작성자(프로필/이름), **총 재생시간** 표기<br>원본 중 **10초 재생**, 클릭 시 **DETL** 이동<br>10초 이후 반투명 회색 오버레이 “눌러서 자세히 보기”<br>열람자/작성일시/좋아요/댓글 표기 & 인터랙션 규칙은 FEED1과 동일                                                                                                                                                                                      | 상시    |
| 게시물   | FEED  | 구현 예정 | 부모님 해금 여부 | 업로드한 게시물에서 **부모님 잠금 해금 여부** 확인(현재는 NEWS1로 일부 대체)                                                                                                                                                                                                                                                                                   | -     |

### DETL (게시물 상세)

| 정책 항목 | 기능 ID | 순위   | 기능명      | 상세 설명                                                                                                                                                                                                                                                                                                               | 배치 조건 |
| ----- | ----- | ---- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- |
| 상세    | DETL  | 구현 중 | 게시물 상세보기 | 상단: 작성자(프로필/이름) + 더보기 아이콘(수정/삭제)<br>수정: 콘텐츠 타입에 맞게 **UPLD2/UPLD3**로 이동<br>삭제: 재확인 모달<br>콘텐츠 전본: **사진**—하단 도트, 슬라이드 전환 / **동영상**—끝나면 1초 멈춤 후 반복 재생<br>열람자 표기: 1명 `{A}님이…` / 2명 이상 `{A, B} 외…`(프로필 3명까지)<br>작성일시, 게시글, 좋아요(토글 즉시 반영), 댓글(작성/수정/삭제/좋아요/답글 상시 노출·들여쓰기)<br>댓글 정렬 우선순위: ① 부모님이 좋아하는 댓글 ② 좋아요 수 높음 ③ 최신 작성 | 상시    |
