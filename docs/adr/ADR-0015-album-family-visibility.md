# ADR-0015: 앨범 가족 전용 공개 정책

> Architecture Decision Record. 하나의 중요한 의사결정과 그 이유를 기록한다.

| 항목 | 값 |
| --- | --- |
| 상태 | Accepted |
| 날짜 | 2026-08-03 |
| 관련 | LLD-0021, #456 |

## 맥락 (Context)

앨범 피드와 미디어 피드는 `ACTIVE` 상태만으로 조회해 가족 관계가 없는 사용자의 앨범도 노출한다.
상세 조회와 해금 API도 가족 외 앨범 ID를 받으면 접근하거나 포인트를 사용할 수 있다.
앨범은 가족 구성원 간 공유 콘텐츠로 한정해야 한다.

## 결정 (Decision)

앨범의 목록·미디어·상세·해금 접근 대상을 현재 사용자와 같은 가족의 구성원이 작성한 앨범으로 제한한다.
피드 조회는 현재 사용자의 가족 구성원 ID 목록을 한 번 조회해 앨범 ID 커서 쿼리에 전달한다.
상세와 해금은 동일한 가족 구성원 검증을 수행한다.

같은 가족 안에서는 기존 작성자·보호자·시니어 해금 규칙을 유지한다.

## 고려한 대안 (Considered Options)

1. **기존 전체 공개 피드 유지** — 포인트 해금 기능은 유지되지만 가족 외 콘텐츠가 노출된다.
2. **피드만 가족 필터 적용** — 직접 상세 조회와 해금 API가 가족 외 앨범에 접근할 수 있어 정책을 우회한다.
3. **각 앨범 쿼리에 가족 서브쿼리 반복** — 추가 서비스는 없지만 커서·날짜별 쿼리에 같은 권한 조건이 중복된다.

## 결과 (Consequences)

### 긍정

- 가족 외 앨범의 목록·상세·해금 경로를 함께 차단한다.
- 피드와 미디어 피드가 공통 가족 구성원 목록을 사용한다.

### 부정 / 트레이드오프

- 피드 요청마다 가족 구성원을 조회한다.
- 기존에 가족 외 앨범을 해금한 기록은 유지되지만 더 이상 접근 권한을 부여하지 않는다.

## 후속 / 미결정

가족 구성원 수가 피드 쿼리의 `IN` 조건 한계를 넘는 경우의 페이지 성능 최적화는 실제 규모를 측정한 뒤 검토한다.
